# kmap-plot
A small package for Karnaugh maps plotting

# Introduction
This package is intended to simplify drawing of Karnaugh maps with implicant markings.
The resulting figures can be used to illustrate Digital Circuits exercises solutions and teaching materials.

# Requirements
The packages is based on matplotlib.
